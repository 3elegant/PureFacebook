## ✨ Key Features

* **🚫 Reels Blocking:** Automatically hides or blocks the Reels and short-video sections to prevent mindless scrolling.
* **👁️ Media Blurring:** All images and videos are blurred by default to help maintain focus and guard the gaze. Users can view content by clicking a dedicated "View Content" button.
* **⏱️ Session Management:** Allows users to select 5, 10, or 15-minute sessions before starting. The app provides a countdown and alerts the user once the time is up.
* **📖 Spiritual Reminders:** Periodically displays meaningful quotes from the Quran and Sunnah to remind users of their purpose and the importance of time.
* **📥 Image Download Support:** Includes built-in functionality to download and save images directly to the device gallery.
* **🔄 Update Notifications:** Automatically checks for the latest version to ensure you always have access to new features.
